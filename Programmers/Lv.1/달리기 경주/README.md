### 문제 요약
- 달리기 경주를 하며, 경주 결과를 도착 순서에 따라 출력하라.
- 달리기를 하며 선수들이 서로를 추월하는데, 추월 시, 선수의 이름을 불러준다. (선수들은 players 벡터로 받는다.)
- 선수의 이름이 울린 순서대로 들어있는 배열을 callings 벡터로 받는다.(당연히 한 선수가 여러 번 불릴 수 있다.)

### 핵심 로직
1. **데이터 구조**: `unordered_map_`을 2개 사용. 검색에 용이하지만, key 검색 밖에 되지 않는 점을 고려하여, key-value를 거꾸로 하는(선수-순위 and 순위-선수) 맵도 준비하여 검색에 도움을 주며 동기화 시킨다.
2. **로직**:
	- players에서 첫 순서 및 선수 이름을 각 unordered_map에 받아온다.
	- callings에서 불린 선수와 추월당한 선수를 각 맵에서 찾아서 등수를 갱신해준다.
	- 등수 조정이 끝나면, answer에 답을 채워넣는다.
