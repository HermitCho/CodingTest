### 문제 요약
- 로봇 강아지의 산책 경로를 구하는 문제이다.
- 강아지가 산책할 공원의 맵을 S(시작점), O(가도 되는 곳), X(장애물)로 나눠서 표기함.
- 또한 어느 방향으로 얼마나 가는지도 입력값으로 주어지는데, 장애물과 맵 밖으로 나가는 명령은 듣지 않는다.

### 핵심 로직
1. **데이터 구조**: `vector<int>`를 사용.
2. **로직**:
	- 맵의 크기, 현재 위치를 미리 확인.
	- 그 후, for(string route : routes)와 내부에 count를 이용한 for문으로 강아지 이동의 명령 값을 한 걸음씩 분석한다.
	- 예를 들어, E로 2번 가는 경우, X방향으로 +1씩 2번 계산한다.
	- 한 걸음 이동 시, 앞으로 가면서 맵을 뚫는지와 장애물을 마주쳤는지 확인한다.
	- 반복하며 answer를 찾는다.
