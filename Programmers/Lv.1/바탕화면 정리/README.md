### 문제 요약
- 바탕화면에 있는 파일을 정리하려고 한다.
- 드래그로 직사각형 형태의 위치를 지정해 파일을 지울 때, 가장 작은 직사각형을 만드는 법.
- 좌표를 기준으로 답을 내보내라.

### 핵심 로직
1. **데이터 구조**: `각 x, y의 최댓값/최솟값을 int 타입 변수`로 생성.
2. **로직**:
	- 직사각형의 모양 좌표에 관한 문제이기 때문에, 이차원 배열 형태로 for문을 돌림.
	- '#'이 있는 string의 위치를 각 int 변수와 비교하여 x, y의 최댓값/최솟값을 구함.

### 소스 코드
- 본 코드는 동일 폴더 내의 파일에서 확인하실 수 있습니다.
