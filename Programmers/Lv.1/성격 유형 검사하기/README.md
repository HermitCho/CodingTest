### 문제 요약
- 성격 유형을 R-T, C-F, J-M, A-N을 짝으로 하여 총 16가지 경우의 수로 나타낼 수 있다.
- 성격 유형을 나누기 위한 문제의 선택지로 다음이 주어진다.
| choices | 뜻 |
| 1 | 매우 비동의 |
| 2 |비동의 |
| 3 | 약간 비동의 |
| 4 | 모르겠음 |
| 5 | 약간 동의 |
| 6 | 동의 |
| 7 | 매우 동의 |
- 점수에 따라 성격 유형을 분류하라.

### 핵심 로직
1. **데이터 구조**: `map<char, int>` 구조의 맵 사용.
2. **로직**:
	- choices[i]의 값에 따라 perType[survey[i][?]]의 값을 더해준다.
	- 성격 유형 점수가 든 맵을 보며, 각 쌍을 비교하여 더 높은 값을 선택하여 answer에 넣어준다.
