### 문제 요약
- 주어진 N개의 칸을 전부 건너야한다.
- 한 번에 1칸 혹은 2칸 밖에 뛸 수 없다.
- 몇 가지의 경우의 수가 있는지 구하여라.

### 핵심 로직
1. **데이터 구조**: `vector<long long>` 이용.
2. **이용 개념**: 피보나치 수열
2. **로직**:
	- N이 1이나 2인 경우는 예외적으로 처리.
	- 각 칸에 도달하는 방법의 수를 vector로 저장
	- 피보나치 수열을 이용하여 전체 경우의 수를 구한다.
