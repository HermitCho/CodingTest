### 문제 요약
- 최소공배수의 정의는 2개의 공배수 중 가장 작은 값을 이야기한다.
- 정의를 확장해서, 주어진 N개의 수들의 최소공배수를 구하라.

### 핵심 로직
1. **데이터 구조**: 단순 `int` 이용.
2. **알고리즘**: 유클리드 호제법.
2. **로직**:
	- 유클리드 호제법으로 최대공약수를 구한다.
	- 최대공약수를 이용하여 최소공배수를 구한다. ((a / gcd(a, b)) * b)
