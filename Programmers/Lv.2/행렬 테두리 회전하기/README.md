### 문제 요약
- row, columns 크기의 직사각형 행렬이 주어진다.
- 행렬은 맨 위의 행 첫 열부터 아래 행 끝 열까지 숫자가 1부터 순서대로 오름차순 정렬되어 행렬을 가득 채운다.
- 해당 행렬에서 x1, y1 위치와 x2, y2 위치(queries로 전달)를 잡고 해당 직사각형 범위의 테두리 값들만 시계 방향으로 돌릴 것이다.
- 이 때 돌아간 범위 내 가장 작은 값을 출력한다.
- 이 시계 방향 회전을 queries의 개수만큼 수행했을 때, 가장 작은 값들을 모두 출력하라.

### 핵심 로직
1. **데이터 구조**: `vector` 이용.
2. **로직**:
	- rows, columns로 for문을 통해 기본 행렬 생성.
	- queries의 크기만큼 for문 실행
		- 벡터 내 실제 범위 좌표 계산
		- 최소 값 min_val과, 마지막 값 계산을 위한 saveCorner 변수 생성.
		- 윗줄은 범위 내 가장 앞열을 제외하고, 맨 뒷열부터 값을 바로 왼쪽 열의 값으로 바꿔준다.
		- 왼쪽 줄은 범위 내 가장 아래 행을 제외하고, 맨 윗행부터 값을 바로 아래의 값으로 바꿔준다.
		- 아랫줄은 범위 내 가장 뒷열을 제외하고, 맨 앞열부터 값을 바로 오른쪽 열의 값으로 바꿔준다.
		- 오른쪽 줄은 범위 내 가장 윗 행을 제외하고, 맨 아래 행부터 값을 바로 위의 값으로 바꿔준다. 또한 마지막으로 바꾼 값은 그대로 하면 이미 바뀐 값으로 바꾸는 것이기 때문에, 아까 저장한 saveCorner를 대신 넣어준다.
		- 각 줄마다 최솟값 계산을 해준다.
		- 최솟값을 answer에 추가해준다.
	- answer를 출력한다.
