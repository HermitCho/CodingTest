### 문제 요약
- 자연수 x를 y로 변환하고자 한다.
- 변환을 위한 연산 방법은 3가지가 있다.
	1. x + n
	2. x * 2
	3. x * 3
- y가 되기 위한 최소 연산 횟수를 구하여라

### 핵심 로직
1. **데이터 구조**: 단순 `vector<int>` 이용.
2. **알고리즘**: DP(동적 계획법).
3. **로직**:
	- 벡터 dp 생성. (dp[i] = i가 되기 위한 최소 연산 횟수)
	- dp의 요소가 100만이 넘는 큰 값(INF)가 되도록 초기화
	- +n, *2, *3의 경우의 수에 따라 비교하며 다음 dp 체크
		- 세 경우마다 x에 연산했을 때 y보다 작은 경우 그 자리의 dp값과 현재 +1된 비교 값 중 더 작은 값이 자리를 차지함
		- dp[y]가 INF라면 -1을 반환, 더 작은 수가 들어가 있으면 그 수를 반환.
