### 문제 요약
- n개의 송전탑이 존재합니다. (최소 2개에서 최대 100개)
- 이 송전탑들은 전선(wires)을 통해 하나로 모두 연결되어 있으며, 순환 고리가 없는 트리(Tree) 형태.
- 현재 연결되어 있는 여러 개의 전선 중에서 단 하나의 전선을 선택하여 끊음.
- 전선을 하나 끊게 되면, 기존에 하나였던 전체 네트워크가 서로 단절된 2개의 전력망으로 완전히 분리.
- 분리된 2개의 전력망이 각각 몇 개의 송전탑을 포함하게 되는지 계산.
- 이때, 두 전력망이 가진 송전탑 개수의 차이가 최소화되도록(최대한 비슷한 규모로 나뉘도록) 끊어야 할 전선을 찾아서 그 값을 구하여라.

### 핵심 로직
1. **데이터 구조**: `이차원 vector` 이용.
2. **알고리즘**: DFS(깊이 우선 탐색)
3. **로직**:
	- graph라는 노드를 양뱡항으로 참조할 수 있는 배열을 만들어서 각 노드에 따라(graph[0] = 1과 연결된 노드) wires에서 값을 추가한다.
	- dfs에서 next_node를 이용하여 자식 노드를 계속 참조하며 더한다.
	- 끝까지 더해서 나온 값을 전체에서 빼서 기존 최솟값과 비교한다.
	- 마지막까지 계산해서 최솟값을 출력한다.
