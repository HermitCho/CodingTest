### 문제 요약
- 차들이 주차한 시간에 따라 요금을 계산하여 차량번호가 낮은 순으로 출력하라.
- '주차 시간 > 기본 시간 ? 기본 요금 + 주차 시간에 비례한 추가 요금 : 기본 요금'의 형태로 요금이 계산됨.
- 차량이 나가지 않았다면, 오전 12시를 기준으로 요금 일괄 정산.

### 핵심 로직
1. **데이터 구조**: unordered_map<string, int> 등 다양한 배열 사용.
2. **로직**:
	- records 배열 내부 데이터를 for문을 통해 가져온 후, stringstream을 통해 띄어쓰기를 구분하여 데이터를 알맞게 저장한다.
	- timeToMinutes() 함수를 통해 string 데이터를 통해 누적 시간을 체크하기 위해 분으로 변환
	- 'IN' 체크로 입차 시간 체크.
	- 출차 체크, 'OUT'이 없으면 23:59을 기준으로 환산.
	- 마지막 기본 시간을 초과했는지 계산.
		- 넘었다면, 추가 시간에 비례하여 추가 요금을 더함.
		- 넘지 않았다면, 기본 요금만 계산.
