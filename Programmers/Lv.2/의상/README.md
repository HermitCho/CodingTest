### 문제 요약
- 옷의 이름과 종류가 주어진 벡터(배열)이 주어진다.
- 옷을 입는 모든 경우의 수를 구하라.
- 옷은 최소 1가지 이상을 입는다.
- 모든 경우의 수에서는 옷의 종류마다 1가지씩 밖에 입지 못한다.

### 핵심 로직
1. **데이터 구조**: 단순 `map<string, int>` 이용.
2. **로직**:
	- 모든 옷의 종류를 기준으로 각각 몇 벌인지 받는 map을 생성한다.
	- 각 종류 별 의상의 가짓수에 +1을 한 수를 answer에 곱한다.(곱의 법칙)
