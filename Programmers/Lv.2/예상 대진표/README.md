### 문제 요약
- 토너먼트 형식의 대회에서 주어진 번호 A,B가 언제 만나는지를 구하라.
- A, B는 만나기 전까지 무조건 이기며, 부전승이 없도록 총 인원은 짝수명이다.
- 만약 1번이 이기면 다음에는 1번, 2번은 1번, 3번은 2번이 되는 형식이다.

### 핵심 로직
1. **데이터 구조**: 단순 `int` 이용.
2. **로직**:
	- 토너먼트 형식에서 다음 번호가 (a+1)/2가 됨을 이용한다.
	- while문을 통해 두 번호가 같아질 때까지 위 계산을 하면서 ++answer를 해준다.

### 소스 코드
- 본 코드는 동일 폴더 내의 파일에서 확인하실 수 있습니다.
