### 문제 요약
- 이진법으로 된 문자열이 주어진다.
- 주어진 문자열을 해당 조건으로 이진 변환한다.
	1. 문자열의 '0'을 모두 제거한다.
	2. '1'만 남은 문자열의 길이를 잰다.
	3. 문자열의 길이를 이진수로 나타낸다.
- 변환된 문자열 s = "1" 이 될 때까지 반복한다.

### 핵심 로직
1. **데이터 구조**: 단순 `string` 이용.
2. **로직**:
	- 주어진 s의 0을 제거하며 카운트를 샌다.
	- s.length()로 길이를 잰다.
	- 길이를 십진수 -> 이진수로 바꾼다.
	- s == "1"일 때까지 반복한다.
