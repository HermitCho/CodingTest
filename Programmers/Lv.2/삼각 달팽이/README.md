### 문제 요약
- 위쪽이 뾰족한 삼각형 형태의 배열과 숫자 n이 있다.
- 해당 배열을 겉에 있는 숫자 요소들부터 안쪽까지 채워내갈 예정이다.
- 채워나가는 규칙은 다음과 같다.
	- (0, 0)부터 1을 채우며 시작
	- (n, 0)까지 순서대로 +1씩 증가된 수를 넣는다.
	- (n, n)까지 순서대로 이어서 +1씩 증가된 수를 넣는다.
	- (1, 1)까지 순서대로 이어서 +1씩 증가된 수를 넣는다.
	- (n-1, 0)...
- 위 규칙을 수행하다보면, 반시계 방향으로 겉에서부터 순서대로 숫자들이 1~N(+1씩 더해져서 오는 최종 수)까지 달팽이 껍질 모양으로 채워지게 된다.
- 해당 규칙으로 채워진 배열의 요소 값들을 나열한 1차원 배열을 구하여라.

### 핵심 로직
1. **데이터 구조**: `vector<vector<int>>` 2차원 배열 이용.
2. **로직**:
	- triangle 2차원 배열을 삼각형 형태로 초기화 한다.
	- row, col, num 값을 초기화 한다.
	- 이차원 for문으로 삼각형 배열에 값을 채워 넣는다.
		- i는 삼각 배열이 채워지는 방향을 계산
			- i % 3 = 0 (위 ->왼쪽 아래로)
			- i % 3 = 1 (아래 왼쪽 -> 오른쪽)
			- i % 3 = 2 (오른쪽 아래 -> 위)
		- j는 +1 채워지는 한 줄에 대해 계산 (n-i개 채우기)
	- 위 계산을 모두 한 후, 2차원 배열을 1차원 배열로 바꾼 후 출력한다.
