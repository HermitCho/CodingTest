### 문제 요약
- 두 큐가 벡터로 주어진다.
- 두 큐의 합이 같게 되도록 큐의 요소들을 옮기는 작업을 한다.
- 해당 작업은 하나의 큐에서 다른 큐로 요소를 완전 이동시키는 것 까지로 정의된다.
- 해당 작업의 최소 횟수를 구하라.

### 핵심 로직
1. **데이터 구조**: `vector<int>` 이용.
2. **알고리즘**: 투 포인터(Two Pointer)
2. **로직**:
	- 양 큐(q1, q2)의 합을 구한다.
	- 두 합의 평균을 구하여 짝수인지 구한다.(홀수면 같게 만들 수 없으므로 -1 리턴)
	- 두 큐를 연결한 q(벡터) 생성.
	- q에서 각 큐들의 시작점을 p1, p2로 선언 및 정의.
	- 최대 연산 횟수 max_ops = n*4 로 지정.
	- while문으로 각 큐의 합이 동일해질 때까지 계산
		- 같다면 answer 바로 출력.
		- q1의 합(q1이 기준)이 평균보다 크다면, q2에게 현재 위치 p1(맨 앞)의 값 전달. 전달에 따라 p1++로 위치도 변경.
		- q1의 합이 평균보다 작다면, q2가 현재 위치 p2 값 q1에게 전달. p2++로 위치도 변경.
