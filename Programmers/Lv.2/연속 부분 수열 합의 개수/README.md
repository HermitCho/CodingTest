### 문제 요약
- 원형으로 연결된 수열에서 나타날 수 있는 합들의 개수를 구하여라.
- 합들은 연속으로 이어진 n개의 수들의 합만 계산한다.
- n은 1~전체까지 모두 계산한다.

### 핵심 로직
1. **데이터 구조**: 'set' 사용.
2. **로직**:
	- 하나의 인덱스를 for문으로 기준 잡는다.
	- 그 수에서 (i + len -1) % n으로 연속된 인덱스에 있는 수열을 for문으로 계속 더해준다.
	- 더한 결과를 set에 넣어준다.
	- set 안에 들어간 전체 개수를 구한다.
