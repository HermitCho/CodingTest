### 문제 요약
- 양의 정수 n와 k진수를 나타내는 k가 주어진다.
- n을 k진수로 나타낸 후, 아래 조건에 맞는 소수(Prime Number)가 몇 개인지 구하여라.
	1. 0P0처럼 소수 양쪽에 0이 있는 경우
	2. P0처럼 소수 오른쪽에만 0이 있고 왼쪽에는 아무것도 없는 경우
	3. 0P처럼 소수 왼쪽에만 0이 있고 오른쪽에는 아무것도 없는 경우
	4. P처럼 소수 양쪽에 아무것도 없는 경우
	5. 단, P는 각 자릿수에 0을 포함하지 않는 소수입니다. (예를 들어, 101은 P가 될 수 없습니다.)

### 핵심 로직
1. **데이터 구조**: long long과 int를 적절히 사용.
2. **로직**:
	- n을 k로 나누며 k진법으로 자릿수 마다 변환하여 reverse_digits에 넣는다.
	- reverse_digit를 뒤집은 후, 각 요소들을 체크하여 k_ary에 조건에 맞는 경우에 해당 수를 넣는다.
	- isPrime() 함수로 소수인지 체크한다.
