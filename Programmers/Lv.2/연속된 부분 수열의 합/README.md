### 문제 요약
- 비내림차순 정렬 배열과 정수 k가 주어진다.
- 배열에서 연속된 정수 합으로 k를 만들 수 있는 최소 배열 개수를 구하되, 조건이 있다.
	- 연속된 가장 적은 요소 개수여야 한다.
	- 같은 양의 요소를 쓴다면, 앞쪽에 있는 경우를 선택한다.
	- k가 나오는 연속 요소 합은 무조건 존재한다.
- 해당 최소 배열 개수를 나타내는 경우의 첫번째 위치, 마지막 위치를 (a, b)형태로 나타내라.

### 핵심 로직
1. **데이터 구조**: 단순 `vector<int>` 이용.
2. **알고리즘**: 투 포인터(Two Pointer)
2. **로직**:
	- 첫번째, 마지막 요소 위치를 나타내는 left, right를 선언.
	- 합을 저장하는 sum, 해당 합 경우의 배열 길이를 저장하는 min_len 선언.
	- while(right < sequence.size())로 맨 끝까지 계산
		- 현재 경우에서 sum이 k와 같을 때, min_len와 현재 길이를 비교하여 더 짧다면 해당 경우를 최소 경우의 수로 지정.
		- sum <= k 면 게속 sum 더하며 right++로 마지막 위치를 변경함.
		- sum > k면 left++로 첫번째 위치를 변경함.
	- while문 계산을 끝으로 answer를 출력.
