### 문제 요약
- 그래프를 DFS와 BFS로 탐색한 결과를 각각 출력하는 문제
- 방문 가능한 정점이 여러 개인 경우 **번호가 작은 것**부터 방문
- 간선은 **양방향**이며, 여러 개의 간선이 존재할 수 있음

### 핵심 로직
1. **데이터 구조**: `vector<vector<int>>` 인접 리스트 사용
2. **사전 준비**: 작은 번호부터 방문하기 위해 각 인접 리스트 정렬
3. **탐색**:
   - **DFS**: 재귀 구조를 이용한 깊이 우선 탐색
   - **BFS**: `queue`를 이용한 너비 우선 탐색 (방문 처리 시점 주의)
